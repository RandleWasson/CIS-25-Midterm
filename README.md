# CIS-25-Midterm 

## Functions - A and B

For part A I decided to write a simple function in which I was given two floating parameters (length and width), multiply them together to give the calculated area. This would be done by giving one number for length and then another number for width and lastly multiplying them together.
Part B is a simple function to check whether the input number is a prime number or not. Of course inorder for it to tell if its a prime number it can't be divisible by 2 so I had to do a for-loop and inside that for-loop an if-return statement.

## Loops and Arrays - A and B

Part A is just a small for-loop that starts at the even number 2 and goes all the way up to 50 (only printing even numbers of course!).
Part B required me to make an array of size 10. I gave a COUT prompt to enter 10 integers and created a while-loop for all numbers i less than 10. This would identify the integers in the array as elements with the help of a for-loop in the next step. Simple!

## CIN and Variables - A and B

Part A is basically having me write a program with CIN, very repetitive with three steps: Name, Age, and Favorite number.
Part B had me declare and initialize variables for data types (int, float, char, and string) and then print their values. Int gave a number (10), float gave pi and a letter (3.14f), char gave just a letter (A), and string printed out "Hello, World!".

## Logical Operators and IF Statements - A and B

Part A is a simple IF-Statement program with 3 numbers and trying to find which of the three is the largest. Very repetitive in which all I had to do was create IF-Statements and within those I would also add IF-ELSE-Statements in them so it wouldn't be confused when running the program.
Part B was a small program that checks the year inputted from the user is a leap year. All I had to do was create an IF-Statement in which the program would run 2 conditions. 1) If the year was divisible by 4 and not 100. 2) If the year is divisible by 400. If any of these conditions are met, then it would return true meaning the year inputted is a leap year otherwise it would return false.

## Switch Case

Of course I also added operators for the calulation so it would work and all you need to do is input two numbers! However, take note that I also added a feature in which the second number input cannot be 0 when dividing (as with most calculators should function).
